手动授权与兼容性

如果当前 DSM 不支持页面授权，可通过管理员终端执行：

sudo sh /var/packages/PlexLocalBridge/target/admin/gatewayctl.sh enable

HTTPS 使用 Plex 原有证书透传；是否改变 Plex 的远程访问判定，仍取决于其版本与请求。
